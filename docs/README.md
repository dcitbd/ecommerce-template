# Techno World BD - Architecture & System Blueprint

Techno World BD is a comprehensive omni-channel e-commerce platform specifically built for Bangladesh's wholesale, retail, and pre-order market (sourcing from Dubai, Hong Kong, and Russia).

### System Topology
- **Frontend Core**: React 18, Vite, TypeScript, Tailwind CSS, Zustand, Lucide Icons.
- **Backend Services**: Supabase (PostgreSQL with Row Level Security, RPC functions, Edge Functions, Deno).
- **Logistics Adapters**: Pathao, Steadfast, RedX, Paperfly, Sundarban Courier.
- **Financial Gateway**: bKash, Nagad, Rocket, SSLCommerz, COD with automated fraud check engine.

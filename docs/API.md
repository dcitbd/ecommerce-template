# API Documentation

### Endpoints
- `POST /api/v1/orders/create`: Place retail, wholesale, or pre-order.
- `POST /api/v1/fraud/check`: Verify customer fraud risk score across regional delivery networks.
- `POST /api/v1/courier/send`: Transmit consignment to Steadfast/Pathao API.
- `POST /api/v1/auth/otp`: Dispatch mobile OTP for registration, login, and password reset.

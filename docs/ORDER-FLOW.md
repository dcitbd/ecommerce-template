# Order Flow & Dynamic Calculation

### Delivery Formula:
- **Inside Dhaka**: Base rate 90 BDT up to 1.0kg. +20 BDT per additional kg fraction.
- **Outside Dhaka**: Base rate 130 BDT up to 1.0kg. +20 BDT per additional kg fraction.
- **Office Pickup**: 0 BDT delivery charge.

### Wholesale Minimum Quantities:
- Enforced minimum 10 pcs order limit on wholesale items with tiered wholesale rates.

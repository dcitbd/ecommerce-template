# Database Schema & Structure

37 dedicated SQL migration tables covering:
1. Profiles & Roles (RBAC with granular permissions)
2. Catalog: Categories, Brands, Colors, Sizes, Products, Pricing, Stocks, Images
3. Customer Commerce: Carts, Wishlists, Orders, Order Items, Status Timeline, Incomplete Orders, Returns, Reviews
4. Logistics & Operations: Couriers, Delivery Areas, Methods, Payment Methods, Transactions
5. Intelligence: Fraud Checks, Customer Credit Rating (0-100% risk badge), Order Tracking, Notifications, System Activity Logs, Audit Trail.
